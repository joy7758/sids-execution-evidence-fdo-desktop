# 产品一页说明

## 产品名称

智能体运行监测、留痕与审阅交付平台

## 一句话说明

这是一个面向内部试点的桌面平台，用于发现智能体运行结果、检查证据完整性、生成审阅包，并以中文优先的 PDF 报告完成审阅交付。

## 解决的问题

智能体运行后，试点用户通常需要回答几个问题：

- 这次运行有没有留下可审阅的证据
- 校验回执是否存在
- 摘要和附属文件是否齐全
- 是否可以生成审阅包
- 最终交付物在哪里
- 普通审阅人员能不能直接看懂结果

本平台把这些问题收敛成一条桌面流程。

## 当前核心能力

- 自动检查默认运行结果收件箱：`~/AgentEvidence/runs/`
- 展示最近运行列表和状态卡片
- 展示单次运行详情，包括证据完整性、附属文件和政策检查项
- 对完整运行一键生成审阅包
- 对不完整运行提示修正路径
- 生成中文优先审阅报告
- 把 PDF 报告作为第一交付物
- 保留 Markdown 报告作为技术或中间格式

## 目标用户

- 技术接入人：负责把智能体运行结果输出到指定目录
- 审阅 / 运营人员：负责查看运行状态、生成审阅包、交付报告
- 非技术内部用户：负责打开 PDF 报告并理解本次运行是否可审阅

## 典型使用路径

1. 打开桌面端
2. 首页自动发现最近运行
3. 查看运行列表和状态卡片
4. 进入运行详情，确认缺项和政策检查项
5. 点击“生成审阅包”
6. 在结果页打开 PDF 报告
7. 将审阅包或 PDF 提交给试点联系人

## 当前交付重点

本试点交付包重点验证主路径是否成立：

- 自动发现
- 状态判断
- 运行详情
- 审阅包生成
- 中文报告
- PDF 第一交付物
- 反馈收集
