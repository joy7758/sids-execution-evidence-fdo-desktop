# 平台能力边界

## 当前版本范围

当前试点版本只覆盖 macOS 内部桌面流程：

- 运行结果收件箱
- 最近运行列表
- 运行详情页
- 一键审阅包主路径
- PDF 第一交付物
- 政策检查项展示

## 已明确支持

- 默认中文界面
- 运行结果目录自动识别
- 三件套识别：
  - 证据包文件
  - 校验回执文件
  - 摘要文件
- 附属文件识别：
  - manifest
  - public key
  - runtime events
- 审阅包生成
- 中文优先审阅报告
- PDF 报告正式交付
- Markdown 报告技术保留
- 私钥默认排除

## 明确不做

当前试点版本不包含：

- Windows
- 签名 / 公证
- 云端 / 账号 / 同步
- provider-running UI
- 完整 policy engine
- 法律合规认证结论
- 自动法条推理
- 大治理平台
- 复杂审批流
- 搜索、筛选、统计看板
- 公网 SaaS
- 采购或营销承诺文案

## 政策检查项边界

桌面端展示的政策检查项只是产品内可见性：

- 运行留痕
- 校验回执
- 审阅交付
- PDF 报告
- 人工复核

这些检查项帮助用户理解当前运行状态，不代表法律结论，也不替代正式合规审查。

## 输出边界

主输出仍然是：

- bundle：证据包
- receipt：校验回执
- summary：摘要

Review Pack 仍然只是整理 / 渲染层。PDF 报告是正式交付格式，但不是新的核心主输出。
