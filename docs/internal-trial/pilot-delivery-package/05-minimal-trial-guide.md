# 最小试用手册

## 试用目标

本手册用于帮助试点用户完成一次最小闭环：

运行结果目录 → 运行详情 → 生成审阅包 → 打开 PDF 报告 → 提交反馈

## 准备工作

需要：

- macOS 试点机器
- Review Pack Desktop 内部版本
- 本交付包目录
- 可写输出目录

## 方式一：使用样例目录

1. 打开 Review Pack Desktop
2. 选择“导入运行结果”
3. 选择 `samples/run-result/`
4. 查看运行详情
5. 确认三件套已识别
6. 查看政策检查项
7. 点击“生成审阅包”
8. 选择输出目录
9. 生成完成后打开 PDF 报告

## 方式二：使用默认收件箱

如果技术接入人已经把运行结果放入：

- `~/AgentEvidence/runs/`

则试点用户可以：

1. 打开 Review Pack Desktop
2. 在首页查看最近运行
3. 选择一条完整运行
4. 进入详情
5. 点击“生成审阅包”
6. 在结果页打开 PDF 报告

## 如何理解结果页

结果页优先展示：

- PDF 报告
- 保存位置
- 打开 PDF 报告
- 复制 PDF 路径
- 打开文件夹

Markdown 报告和技术文件在详情中查看，不作为第一交付物。

## 如何判断一次试用成功

一次试用成功至少应满足：

- 能看到最近运行或成功导入运行结果目录
- 能看到运行详情和证据完整性
- 能看到政策检查项
- 能生成审阅包
- 能打开 PDF 报告
- 输出目录中不包含私钥
