# 试点验收清单

## 1. 产品路径验收

- 首页能自动检查运行结果收件箱
- 首页能显示最近运行列表
- 状态卡片能区分完整运行和不完整运行
- 可以从列表进入运行详情
- 详情页能显示证据完整性
- 详情页能显示政策检查项
- 完整运行可以进入生成审阅包路径
- 不完整运行会进入修正路径

## 2. 输出物验收

- 审阅包生成成功
- 输出目录包含 `index.json`
- 输出目录包含 `primary/bundle.json`
- 输出目录包含 `primary/receipt.json`
- 输出目录包含 `primary/summary.json`
- 输出目录包含 `review/report.md`
- 输出目录包含 `review/report.pdf`
- 输出目录不包含私钥文件

## 3. 中文优先验收

- 首页主状态为中文
- 运行详情为中文优先
- 政策检查项为中文优先
- 结果页主动作为中文
- 审阅报告第一眼是中文
- PDF 报告为中文优先

## 4. 交付体验验收

- 结果页把 PDF 报告作为第一交付物
- Markdown 报告没有抢第一屏
- 用户能打开文件夹
- 用户能复制 PDF 路径
- 用户能回到最近运行继续处理其他运行

## 5. 边界验收

- 没有出现 Windows 承诺
- 没有出现签名 / 公证承诺
- 没有出现云端 / 账号 / 同步承诺
- 没有出现完整策略引擎承诺
- 没有出现法律合规认证结论
- 没有出现采购或营销承诺话术

## 6. 反馈收集验收

- 已收集至少一份完整反馈模板
- 反馈能定位到页面和步骤
- 阻塞问题有复现步骤
- 输出物问题能提供目录或截图

## 7. 通过条件

试点可以通过本轮验收，当以下条件同时满足：

- 主流程能完成
- PDF 报告能打开
- 运行详情和政策检查项能被试点用户理解
- 没有私钥进入输出
- 没有阻塞级问题
- 反馈主要集中在可后续优化项
