# M4 一键审阅包流程优化

## 目标

M4 不新增大页面，只优化现有主流程，让用户从“发现一条可用运行”到“拿到 PDF 审阅包”之间的步骤更短、更清楚、更少犹豫。

## 完整运行主路径

完整运行遵循同一条主路径：

1. 首页状态区或最近运行卡片显示“可生成审阅包”
2. 主动作统一为“生成审阅包”
3. 如果输出目录已经明确，直接进入生成前确认页
4. 如果输出目录尚未明确，先进入输入准备页补输出位置
5. 进入生成前确认页后，一键生成审阅包
6. 结果页第一屏直接展示 PDF 报告与保存位置

## 不完整运行修正路径

不完整运行不再伪装成可以直接生成。

统一规则：

1. 首页、列表卡片、详情页的主动作统一为“处理此运行”
2. 点击后直接进入修正路径，而不是误导进入生成
3. 修正路径继续保留：
   - 重新选择目录
   - 高级手动修正
4. 只有缺项补齐后，才继续进入生成前确认页

## 主动作统一规则

完整运行：

- 首页状态区：生成审阅包
- 最近运行卡片：生成审阅包
- 运行详情页：生成审阅包
- 生成前确认页：生成审阅包

不完整运行：

- 首页 / 列表 / 详情：处理此运行
- 修正页内再提供高级手动修正

## 结果页回流规则

结果页继续保持 PDF 第一交付物，不改这个主逻辑。

M4 新增的回流规则是：

1. 完成一次交付后，可以直接“返回最近运行”
2. 用户可以顺手回到监测首页，继续查看其他运行
3. 结果页不再是流程终点或死胡同

## 与 M5 的边界

M4 只优化单次主路径，不扩展范围。

M4 不做：

- 大图表
- 搜索
- 复杂筛选
- 统计看板
- 政策检查项展示
- 新设置页
- 新报告逻辑
- 新 PDF 逻辑

这些留给后续阶段处理。
