# U2 PDF 第一交付位置说明

## 1. U2 目标

U2 不改核心审阅包结构，只调整桌面端结果页的交付层级。

这一轮只解决一件事：

- 让 Result 页第一屏先突出 PDF 报告，而不是先展示 Markdown 或技术文件列表

## 2. 为什么 PDF 是正式交付格式

- PDF 更适合中国客户直接查看、发送和打印
- PDF 更接近正式交付材料
- Markdown 继续保留，但它更适合技术检查和中间处理

## 3. Markdown 的新位置

Markdown 报告仍然保留，但在产品中的位置已经后移：

- 技术格式
- 中间格式
- 调试和技术检查可用

它不再是结果页第一层要突出的正式交付物。

## 4. Result 页第一屏应突出什么

Result 页第一屏应只突出：

- 审阅包已生成
- PDF 报告
- 保存位置
- 打开 PDF 报告
- 打开文件夹
- 复制 PDF 路径

技术文件应后置到“查看输出详情”中。

## 5. PDF 缺失时如何优雅降级

如果 `review/report.pdf` 没有找到：

- 不影响当前成功结果页
- 继续保留 Markdown 报告入口
- 明确提示“当前仍可查看 Markdown 报告（技术格式）”
- 不让用户看到崩溃或空白结果页
