# UI 设计原型说明

本目录存放桌面端用户友好 UI 的低保真原型，用于后续实现前对齐页面结构、信息层级和主动作。

## 文件

- `home-dashboard.svg`：首页状态区 + 最近运行列表
- `run-detail.svg`：运行详情页 + 证据完整性 + 政策检查项
- `result-delivery.svg`：结果页 + PDF 第一交付物

## 使用方式

直接用浏览器、预览应用或设计工具打开 SVG 文件即可查看。

## 设计边界

这些原型只表达：

- 页面结构
- 主要文案
- 状态层级
- 主动作和次级动作

这些原型不表达：

- 最终图标
- 最终字体
- 复杂动效
- 完整响应式规则
- 代码实现细节
