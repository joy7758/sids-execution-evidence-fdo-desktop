## 为什么选它

1. round7 已完成 official-template mode 的 source 清理。
2. round7 已经把 Branch A 边界、single-blind hygiene、portal 文本冻结到较稳定状态。
3. round8 的任务不是重写 source，而是把 round7 的 clean source 变成唯一推荐 Overleaf/import/handoff 包。

## 为什么不再从更早 round 重打包

- round6 仍处在“official template 接入 + source 成型”的阶段。
- round7 才第一次把 clean upload bundle、Overleaf handoff、portal frozen text 和 upload gate 放到同一层。
- 因此 round8 应以 round7 clean source 为唯一可信打包基底，而不是回退到更早 round。
