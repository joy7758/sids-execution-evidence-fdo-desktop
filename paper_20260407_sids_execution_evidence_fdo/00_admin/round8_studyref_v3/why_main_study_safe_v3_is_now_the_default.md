# Why Main Study Safe V3 Is Now The Default

## 为什么 v3 默认路径比 v2 更稳

1. v3 的 compile-facing bib 已经完全纯英文
2. v3 不再把中文学习字段留在默认 `.bib`
3. v3 更接近最终 submission path

## 为什么学习层不应再绑在 compile-facing `.bib`

1. 当前机器仍然是 overleaf-only handoff
2. compile-facing 路径应尽量降低编码和 BibTeX 风险
3. 学习层更适合独立 sidecar 文件

## 为什么这更适合当前现实条件

1. 本地没有 TeX 编译真值
2. Overleaf 路径应优先稳定
3. v3 让：
   - bibliography 编译层
   - 学习阅读层
   - submission truth
   三者彻底分离
