# Reference Scope Boundary

## 本轮会处理什么

- `refs.bib`
- references list
- reference notes
- references-in-use 清单
- 带 bibliography 的 tex source
- 中文参考文献工作版 Overleaf 包
- 英文恢复基底与恢复操作卡

## 本轮不会处理什么

- scientific claims
- methods / results / evaluation / conclusion 的 scientific 内容
- code / schema / examples / tests / demo
- Branch A / Branch B 判断
- Sovereign-pFDO 线
- 代谢 / 熵 / 图表线

## 边界说明

- 如果某个文件既含 scientific text 又含 bibliography，则只改 bibliography layer。
- 如果某个英文正文历史版本只是恢复基底或审计快照，则可以故意保留英文。
