## Contributions

- A minimal profile for representing one operation accountability statement.
- An operation-centered object model that binds actor, subject, policy, provenance, evidence, and validation.
- A JSON Schema that makes the current profile concretely checkable.
- A profile-aware validator with four explicit validation stages.
- A command-line validation path for exercising the shipped artifact.
- One repo-backed valid example and three controlled invalid examples.
- Test anchors for the operation-accountability path.
- One runnable single-path metadata-enrichment demo that produces review artifacts.
