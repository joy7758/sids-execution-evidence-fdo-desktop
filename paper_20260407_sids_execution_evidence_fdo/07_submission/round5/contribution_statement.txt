This submission contributes a small but reviewable engineering result for FDO and data-space settings. It shows that one agent-mediated operation can be represented as a single-operation accountability object with a bounded validation path. The artifact surface is deliberately narrow and repo-backed: a profile specification, a JSON Schema, a reference validator CLI, one valid example, three controlled invalid examples, tests, and one runnable walkthrough. The paper does not argue from scale. It argues from closure. That closure matters because it lets reviewers inspect one concrete object model, one rule surface, and one exercise path together. For a workshop audience, the value is a compact, verifiable, and reproducible accountability artifact rather than a larger but weaker claim set.
