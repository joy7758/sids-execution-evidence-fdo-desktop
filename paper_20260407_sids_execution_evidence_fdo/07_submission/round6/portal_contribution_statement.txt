This submission makes a narrow engineering contribution rather than a broad platform claim. It presents a minimal verifiable profile for a single-operation accountability object in an FDO and data-space setting, together with a validator path that checks schema conformance, reference closure, cross-field consistency, and bounded integrity recomputation. The contribution is grounded in a small repo-backed artifact surface: one valid example, three controlled invalid examples, tests, a reference validator CLI, and one runnable walkthrough. The value of the paper is not scale or scope, but closure. Reviewers can assess one bounded object model, one bounded validation path, and one inspectable artifact boundary without requiring a larger deployment story.
