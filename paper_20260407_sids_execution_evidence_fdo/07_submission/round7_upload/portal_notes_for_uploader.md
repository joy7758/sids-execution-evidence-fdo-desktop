# Portal Notes For Uploader

可直接粘贴：

- `portal_title.txt`
- `portal_abstract.txt`
- `portal_keywords_subjects.txt`
- `portal_contribution_statement.txt`
- `portal_data_availability.txt`

仍需人工确认：

- `portal_author_block.txt`
- `portal_funding_statement.txt`
- `portal_conflict_statement.txt`

上传顺序建议：

1. 先导入 Overleaf 包并生成 PDF
2. 确认 PDF 页数 `<= 6`
3. 再把 author / funding / conflict 最终文本同步到 portal
4. 最后上传 PDF 与 source zip
