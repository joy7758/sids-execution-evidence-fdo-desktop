# Bilingual Reference Examples

## Example 1: journal article

### canonical 英文 bib

```bibtex
@article{kahn2006framework,
  author = {Kahn, Robert and Wilensky, Robert},
  title = {A framework for distributed digital object services},
  journal = {International Journal on Digital Libraries},
  volume = {6},
  number = {2},
  pages = {115--123},
  year = {2006}
}
```

### safe bilingual bib

```bibtex
@article{kahn2006framework,
  author = {Kahn, Robert and Wilensky, Robert},
  title = {A framework for distributed digital object services},
  x_zh_title = {中文暂译：分布式数字对象服务框架},
  journal = {International Journal on Digital Libraries},
  volume = {6},
  number = {2},
  pages = {115--123},
  year = {2006}
}
```

### visible bilingual 人读条目

```text
Kahn, Robert; Wilensky, Robert. 2006. A framework for distributed digital object services【中文暂译：分布式数字对象服务框架】.
```

## Example 2: W3C document

### canonical 英文 bib

```bibtex
@techreport{moreau2013provdm,
  author = {Moreau, Luc and Missier, Paolo},
  title = {{PROV}-{DM}: The {PROV} Data Model},
  institution = {World Wide Web Consortium},
  type = {W3C Recommendation},
  year = {2013},
  url = {https://www.w3.org/TR/prov-dm/}
}
```

### safe bilingual bib

```bibtex
@techreport{moreau2013provdm,
  author = {Moreau, Luc and Missier, Paolo},
  title = {{PROV}-{DM}: The {PROV} Data Model},
  x_zh_title = {PROV 数据模型},
  institution = {World Wide Web Consortium},
  type = {W3C Recommendation},
  year = {2013},
  url = {https://www.w3.org/TR/prov-dm/}
}
```


```bibtex
  pages = {1393--1410},
  year = {2019}
}
```
