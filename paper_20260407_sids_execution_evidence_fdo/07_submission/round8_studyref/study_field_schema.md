# Study Field Schema

## `x_zh_title`

- 作用：
  - 存放英文标题对应的中文 subtitle annotation
- 示例：
  - `x_zh_title = {中文暂译：分布式数字对象服务框架}`
- 是否允许进入 submission：
  - 否
- 是否默认渲染：
  - 否

## `x_study_terms`

- 作用：
  - 存放该条目最关键的学习术语、学习读法与中文义项
- 示例：
  - `x_study_terms = {DOIP（字母读法：D-O-I-P）, protocol（中文义项：协议；学习近音：普罗托科尔）}`
- 是否允许进入 submission：
  - 否
- 是否默认渲染：
  - 否

## `x_study_gloss`

- 作用：
  - 存放该条目在当前工程语境下的一句学习说明
- 示例：
  - `x_study_gloss = {本文语境下用于说明数字对象接口协议与对象交互规范。}`
- 是否允许进入 submission：
  - 否
- 是否默认渲染：
  - 否
