# Reference Translation Policy

## 当前模式

当前采用：`中文参考文献工作模式`

## 统一规则

1. 作者名
   - 默认保留原文拼写
   - 不擅自把外文作者名翻成中文

2. 文献标题
   - 统一给出中文标题
   - 不确定时标注 `中文暂译`

3. 机构 / 会议 / 期刊 / 组织名
   - 若有稳妥常见中文表达，可写“中文（原文）”
   - 若没有稳妥中文，不强译，保留原文，但整条著录格式使用中文语法

4. 文献类型术语统一中文化
   - `Version` -> `版本`
   - `Working Group Note` -> `工作组说明`
   - `Recommendation` -> `推荐标准`
   - `Technical Report` -> `技术报告`
   - `Protocol Specification` -> `协议规范`
   - `Internet-Draft` -> `互联网草案`

5. DOI / URL / 卷(期) / 页码
   - 保持原样

6. version / publication date / note 等说明
   - 改成中文表述

7. 不新增新来源
   - 不补不存在的 DOI
   - 不新增当前项目外的引用

8. citation key
   - 完全不变

9. 不确定译名处理
   - 不冒充官方中文名
   - 使用 `中文暂译`
   - 在 `uncertain_translation_items.md` 中单独记录
