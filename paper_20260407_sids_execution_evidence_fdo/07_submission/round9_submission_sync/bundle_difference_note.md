# Bundle Difference Note

## 这两个 zip 的区别

- `overleaf_bundle_working_default_round9.zip`
  - 基于默认工作路径
  - 用于继续工作、外部编译预备、最后的小修

- `overleaf_bundle_submission_truth_round9.zip`
  - 基于最终锁定的 submission truth 路径
  - 用于真正生成提交前 PDF

## 什么时候用 working bundle

- 还在继续改稿
- 还没有切到最终上传流程
- 想先做一次 Overleaf 编译检查

## 什么时候必须切到 submission truth bundle

- scientific text 已冻结
- author / funding / conflict 准备开始最终填写
- 要生成真正用于上传的 PDF
